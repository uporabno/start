KAJ DELA
--------
Fetchá DHMZ (Hrvaški meteorološki zavod) stran s temperaturami morja.
Python parser (BeautifulSoup) izvleče tabelo s postajami in temperaturami.
Podatki se NABIRAJO - vsak dan doda nov zapis (ne prepiše).

VSEBINA JSON
------------
Array zapisov, en element na dan:

    "datum": "2026-09-09",
    "postaje": {
      "Opatija A": {"07h": 24.7, "14h": 24.9, "17h": 25.4},
      "Zadar A":   {"07h": 26.0, "14h": 26.3, "17h": 26.3},
      ...
    }
  },
  ...
]

----------
