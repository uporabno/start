TEMPERATURA-ZRAKA.JSON - NAVODILA
==================================

Izhodni file: actions/temperatura-zraka.json
GitHub Action: .github/workflows/temperatura-zraka.yml (Fetch TemperaturaZraka)

URNIK
-----
Vsak dan ob 17:00 CET (15:00 UTC)
Cron: 0 15 * * *

URL
---
https://meteo.hr/podaci.php?section=podaci_vrijeme&param=hrvatska1_n

KAJ DELA
--------
Fetchá DHMZ (Hrvaški meteorološki zavod) stran z meteorološkimi podatki.
Python parser (BeautifulSoup) izvleče detajlno tabelo s postajami.
Podatki se NABIRAJO - vsak dan doda nov zapis (ne prepiše).

VSEBINA JSON
------------
Array zapisov, en element na dan - samo temperature po krajih:
[
  {
    "datum": "2026-09-10",
    "ura": "17:05",
    "postaje": {
      "Zagreb-Maksimir": 22.4,
      "Split": 28.1,
      "Dubrovnik": 27.3,
      ...
    }
  },
  ...
]

POSTAJE (~50)
-------------
Zagreb (3 lokacije), Rijeka, Split, Dubrovnik, Osijek, Zadar, Šibenik,
Pula, Rovinj, Varaždin, Krapina, Karlovac, Gospić, Zavižan, in druge.

STOLPCI V TABELI (vir)
----------------------
Ime postaje, smer vetra, hitrost vetra (m/s), temperatura zraka (°C),
relativna vlažnost (%), zračni tlak (hPa), tendenca tlaka (hPa/3h),
stanje vremena.
→ V JSON se shrani SAMO temperatura zraka (°C) po postajah.
